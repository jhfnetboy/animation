# 第 1 课（直觉篇·语言与空间）：《词语的星辰大海：AI 如何把人类语言变成宇宙坐标？》

## 一、课程定位与年级适配

- **课程定位**：整套课程的认知破冰第一课。让学生彻底放下“计算机靠背字典理解人类说话”的旧观念，用“切积木”和“星际坐标”建立大语言模型（LLM）最底层的空间世界观。
- **核心突破点**：理解 **Tokenization（词元化）** 与 **Embedding（向量嵌入空间）**，明白为什么 AI 能做语义联想与跨概念类比（如 `国王 - 男人 + 女人 = 女王`）。

| 适配学段 | 认知起点与难点 | 分层教学目标 | PBL 产出复杂度要求 |
| :--- | :--- | :--- | :--- |
| **初中组（7–9 年级）** | 熟悉二维平面直角坐标系 $(x, y)$；尚未学高维空间与线性代数向量加法；容易拟人化理解 AI | 1. 能用“按常见词根切积木”解释为什么大模型数不清 `Strawberry` 里的 `r`<br>2. 能在 2D/3D 星座图上理解“意思越近，距离越近”<br>3. 能手动完成“A - B + C = D”的直觉类比实验 | 绘制包含 **10–12 个概念节点、3 个星群** 的手绘/数字化星座图，写出 **1 组** 跨界联想公式并口头解释合理性 |
| **高中组（10–12 年级）** | 已具备平面/空间向量加减与坐标系投影概念；对多特征维度抽象有接受度 | 1. 理解 BPE（字节对编码）按高频子词切分对算力与多语言 Token 税的影响<br>2. 理解“高维特征打分”（如用 5 个隐形维度给词打分就是 5 维坐标）及余弦相似度直觉<br>3. 能构造精确的跨领域语义向量偏移公式 | 绘制包含 **15+ 概念、标注至少 3 条隐形语义坐标轴** 的高维星图投影，提出 **2 个** 可验证的跨界创新连接点并附特征维度打分表 |

## 二、核心教学隐喻（非纯 Coding 解释法）

### 1. 隐喻 A：积木切割机（Tokenizer）
- **生活类比**：AI 是一个看不懂汉字偏旁或英文拼写的“外星盲人积木匠”。当人类递给它一张写着字的长纸条时，它必须先把纸条喂进一台**“高频积木切割机”**：经常一起出现的字母或汉字（比如 `ing`、`中国`、`苹果`）会被保留成一整块积木，生僻词或长单词会被咔嚓切成几小块碎积木。每个积木背面只印着一个**纯数字编号（Token ID）**。
- **反直觉瞬间（教学抓手）**：正因为 AI 看到的是“编号积木”而不是“单个字母”，当你问它 `Strawberry` 有几个 `r` 时，它手里拿到的其实是 `Straw`（#3021）和 `berry`（#1984）两块积木——它根本没把字母拆开数！

### 2. 隐喻 B：语义引力星空（Embedding 高维空间）
- **生活类比**：切出来的每块积木如何产生“意思”？宇宙给每块积木发了一张**“特征打分身份证”**：如果在“有生命-无生命”、“皇室权力-平民”、“男性-女性”、“温暖-冰冷”等几百个维度上给每个词打分（比如 `国王 = [皇权:0.99, 男性:0.95, 生命:0.90]`），这组分数就是它在宇宙中的**精确星际坐标**！
- **星座与星际跃迁**：具有相似分数的词受到“语义引力”吸引，自动聚集成一片星座（猫、狗、虎聚在“动物星云”，咖啡、奶茶、可乐聚在“饮品星云”）。而在这个坐标系里移动一步，就是概念变换：从“国王”飞向“女人”方向、减去“男人”方向，正好落到“女王”所在的坐标点！

### 3. 隐喻与真实原理映射及纠偏表

| 隐喻要素 | 对应 AI 真实原理 | 课堂必须戳破的常见误区 |
| :--- | :--- | :--- |
| 高频积木切割机 | Tokenizer（BPE / Tiktoken 子词分词） | ❌ 误区：“一个字就是一个 Token” → ✅ 纠偏：英文常见词常是 1 Token，中文往往 1–2 个汉字一个 Token，稀有词和 Emoji 会碎成多个字节 Token |
| 几百个特征维度的打分表 | Embedding Vector（如 1536 维或 4096 维词嵌入向量） | ❌ 误区：“坐标轴是程序员手动标好‘性别/皇权’的” → ✅ 纠偏：维度是神经网络读完海量文本自己涌现的隐形统计特征，往往没有单一汉字名字 |
| 星际距离与跃迁 | 向量点积 / 余弦相似度与向量线性运算 | ❌ 误区：“AI 先理解意思再找坐标” → ✅ 纠偏：恰恰相反，**坐标的位置和距离本身，就是 AI 眼中的“意思”** |

## 五、课堂互动沙盒实验引导步骤

> **对应演示工具**：**Demo 2（课件 1：Tokenizer 与向量天平）**

1. **实验一：寻找“切碎之谜”（Tokenizer 观察）**
   - **Step 1 基准观察**：在课件 1 输入框输入中文句 `人工智能改变世界`，记录切出了几块积木、哪两个字粘在一起。
   - **Step 2 对比切换**：输入英文句 `Artificial Intelligence changes the world`，再输入同义网络热梗/生僻成语（如 `绝绝子` 或 `饕餮盛宴`），以及 `Strawberry`。
   - **Step 3 核心提问**：“为什么同一个意思，有些语言只用了 4 块积木，有些用了 12 块？如果你是算力公司老板，Token 切得越碎意味着什么？”（引导发现“算力成本与字符计数盲区”）。
2. **实验二：校准“向量天平”（Embedding 维度探索）**
   - **Step 1 锁定锚点**：选中星空中的目标词（如 `狮子`、`图书馆`、`咖啡`）。
   - **Step 2 调控维度滑块**：手动拨动课件界面上的三个可见维度天平（例如：【野性↔秩序】、【冰冷↔温暖】、【实体↔抽象】），观察当前选中的词在星空中向哪个星座缓慢漂移。

3. **教师控场与救场预案**：
   - *若学生觉得“不就是查同义词词典吗？”*：立即让学生在沙盒里输入反义词（如 `热` 和 `冷`、`黑` 和 `白`），展示它们在空间里其实离得很近（因为共享“温度/颜色”维度），彻底打破“同义词词典”的错误联想。

## 二、核心教学隐喻（非纯 Coding 解释法）

### 1. 隐喻 A：多束交织深海探照灯（Self-Attention 自注意力）
- **生活类比**：想像一个漆黑的深海剧场，句子里的每个词都站在一根柱子上。刚进来时大家互不认识。当读到“小明把书包扔在地上，因为**它**太沉了”里的 **“它”** 时，舞台顶部同时亮起好几束不同颜色的**深海探照灯**：
  - **红色语法探照灯**扫向“书包”和“地上”，光柱打在“书包”上最刺眼；
  - **蓝色物理常识探照灯**感知“太沉了”，瞬间加粗了“书包”和“它”之间的能量光缆；
  - 于是，“它”吸收了“书包”的光芒，瞬间明白自己是谁！
- **多头意义**：单束灯只能看一件事（比如只找主语），十几束灯同时照射（Multi-Head Attention），才能既看懂逻辑、又品出反讽或双关。

### 2. 隐喻 B：蒸汽朋克弹珠抽奖漏斗（Next-Token Prediction & Temperature）
- **生活类比**：探照灯把前面所有词的含义汇总后，传到模型背后的**“蒸汽朋克机械室”**。这里没有“真理标准答案书”，只有一排标着候选词的**概率漏斗**（比如输入“床前明月___”，`光` 漏斗口占了足球场那么大，`亮` 只有杯口大，`饼` 只有针眼大）。
- **Temperature 锅炉火力**：每一次生成下一个字，系统就往漏斗上方扔一颗黄铜弹珠：
  - **Temperature = 0（冰封绝对零度）**：锅炉熄火，漏斗上方没有热气流，弹珠垂直掉进最大口子的 `光` —— 稳定、零意外、略显枯燥；
  - **Temperature = 1.5（狂暴蒸汽过载）**：锅炉猛烈喷气，热浪把弹珠吹得在半空乱跳！原本针眼大的“苹果/飞船”漏斗也可能接住弹珠！这就是为什么高温度能写出神来之笔的诗句，也必然伴随着**“一本正经编造历史人物与虚假数据”（幻觉 Hallucination）**。

### 3. 隐喻与真实原理映射及纠偏表

| 隐喻要素 | 对应 AI 真实原理 | 课堂必须戳破的常见误区 |
| :--- | :--- | :--- |
| 深海探照灯连接光柱粗细 | Attention Weight（Query 与 Key 匹配后的注意力权重矩阵） | ❌ 误区：“AI 先看完整个对话才一口气写出全文” → ✅ 纠偏：生成时它是**逐个 Token 单向接龙**（自回归），每吐出一个新词，都要重新开一遍探照灯算下一词 |
| 漏斗口的大小比例 | Softmax 输出的下一词元条件概率分布 $P(w_t \mid w_{<t})$ | ❌ 误区：“AI 说胡话是因为程序出了 Bug 或黑客攻击” → ✅ 纠偏：幻觉不是软件 Bug，而是**概率采样的天然代价**——在 AI 眼里，“合理顺口”永远优先于“真实发生过” |
| 蒸汽锅炉火力大小 / 漏斗挡板 | Temperature（温度缩放系数）与 Top-P（核采样阈值过滤） | ❌ 误区：“把 Temperature 调成 0 就再也不会有幻觉了” → ✅ 纠偏：若最高概率词本身就是错的（比如语料错误或无上下文线索），Temp=0 只会让它**非常稳定且坚定地胡说八道** |

## 五、课堂互动沙盒实验引导步骤

> **对应演示工具**：**Demo 2（课件 2：它知道自己是谁）** & **Demo 3（模式 A：概率弹珠机）**

1. **实验一：指代破案（Demo 2 课件 2）**
   - **Step 1**：选定预设歧义句 `奖杯放不进手提箱，因为它太___了`。
   - **Step 2**：分别把结尾切换为 `大` 和 `小`。
   - **Step 3**：用鼠标点击代词 `它`，观察探照灯最粗的光柱是如何从 `奖杯` 瞬间跳到 `手提箱` 的——理解“语境如何决定语义归属”。
2. **实验二：玩转蒸汽锅炉（Demo 3 模式 A）**
   - **Step 1 冰点基线（Temp = 0.0）**：在弹珠机输入前导句 `在零下两百度的月球暗面，科学家发现了一颗___`，连续点击“生成下一词” 3 次，观察是否每次都掉进几乎相同的平庸词（如 `石头 / 陨石坑`）。
   - **Step 2 最佳平衡（Temp = 0.7, Top-P = 0.9）**：重新采样 3 次，记录兼顾合理性与新意的结果。
   - **Step 3 狂暴沸腾（Temp = 1.8）**：观察蒸汽热浪如何把弹珠吹到极小概率词上，记录生成出的“胡言乱语或惊艳诗意”（如 `怀表 / 融化的吉他`），并尝试收窄 `Top-P = 0.3` 体会“如何只给发散加一条安全围栏”。
3. **教师控场与救场预案**：
   - *若在 Temp=1.8 时刚好抽中了一个看似合理的词，学生质疑“也没幻觉啊？”*：立即连续点击“连发 5 轮接龙”，由于前面已经偏离主轨 1 步，后续所有探照灯都会跟着这颗“野弹珠”集体跑偏，几秒内展示“雪崩式胡说八道”。

## 六、PBL 实战任务卡与 Prompt 脚手架

### 📋 任务卡：可控创造力实验——“冰与火的双面写手”
- **任务情景**：你要为一本面向青少年的《宇宙奇观》双栏杂志同时供稿：左栏是**“绝对不能瞎编的零幻觉科学快报”**，右栏是**“打破常规想象的硬核科幻微开篇”**。请你围绕同一个科学对象（推荐：**黑洞事件视界 / 深海热液盲虾 / 记忆移植芯片**）驾驭 AI 完成两极输出。
- **核心动作**：不仅要生成结果，更要演示你如何通过 **上下文锚点（Context Grounding）** 和 **拒答约束** 锁死幻觉，又如何通过 **强迫跨界隐喻** 释放高温创造力。
- **交付物**：《双栏对照实验卡》（含 Prompt 策略对比、AI 原文、以及学生用红笔圈出的“事实核查证据链”）。

### 🧩 结构化 Prompt 脚手架

#### A 栏脚手架：零幻觉科学核查模式（模拟低温 + 强锚点）
```markdown
【角色与安全围栏】
你是一位极度严谨、宁缺毋滥的《自然》科学事实核查编辑。

【硬性约束（防幻觉铁律）】
1. 仅允许基于我下面提供的【参考资料片段】作答，绝对禁止调用你记忆里模糊的扩展知识补充数字、年份或论文作者。
2. 如果答案不在参考资料中，或者存在不确定性，必须明确回答：“【证据不足，拒绝推测】”。
3. 每一句科学结论末尾，必须用 `[依据：原文第X句]` 标注来源锚点。

【参考资料片段】：[学生粘贴一小段经过核实的百科/教材段落]
【需要生成的科普要点】：[学生提问]
```

#### B 栏脚手架：高发散科幻构建模式（模拟高温采样 + 逻辑收敛）
```markdown
【角色与创作模式】
你是一位极具诗意与视觉张力的科幻小说家。现在我们需要围绕【主题，如：深海热液生命】打开高发散脑洞。

【发散探索阶段】
请给我提供 3 个**反直觉、低概率但极具画面感**的世界观假设（严禁使用“外星人、时空隧道、机器觉醒”等陈词滥调），每个假设请用“如果……那么在感官上会像……”来描述。

【人工筛选与收敛（等待我回答后执行）】
先停下，让我从 3 个里挑出最有质感的一个，并加上一条现实物理底线约束，我们再共同写下前 200 字开篇。
```

# 第 3 课（进阶篇·智能体与行动）：《从“缸中之脑”到“钢铁侠战甲”：AI Agent 与自主任务循环》

## 一、课程定位与年级适配

- **课程定位**：从“只会一问一答的聊天框”跨入“能主动跑腿干活的数字生命”。解决学生常问的疑惑：“为什么 ChatGPT 以前连今天几号、我书包里有几本书都不知道，而现在的 AI 却能自己订机票、查文献甚至改代码？”
- **核心突破点**：建立 **LLM（裸大脑） vs AI Agent（智能体）** 的本质区分，掌握 **感知（Perception）— 记忆（RAG）— 工具（Tools）— 规划与反思（ReAct Loop）** 四大组件以及“自我纠错循环”的工程思想。

| 适配学段 | 认知起点与难点 | 分层教学目标 | PBL 产出复杂度要求 |
| :--- | :--- | :--- | :--- |
| **初中组（7–9 年级）** | 习惯把 AI 当成百科全书搜索引擎；不清楚“能说话”和“能动手办事”之间的技术断层 | 1. 能说出“缸中之脑”的 3 大局限（无实时眼耳、无私有记忆、无手脚）<br>2. 能用“雷达/图书馆/机械臂/战术头盔”解释 Agent 四件套<br>3. 能设计出顺序清晰的多步执行流程图与 1 条兜底改错方案 | 针对校园/家庭痛点绘制 1 张 **“战甲装配蓝图”**，包含 **3 个工具模块、1 个私有记事本（记忆）** 与 **1 个报错后绕路重试分支** |
| **高中组（10–12 年级）** | 理解接口（API）与分支条件判断（`if-else` / `while` 循环）基本概念；易忽略“死循环与幻觉越权风险” | 1. 掌握 **RAG（检索增强生成）** 与模型参数内记忆的成本及实时性差异<br>2. 掌握 **ReAct（Reasoning + Acting）** 状态机循环：Thought → Action → Observation → Reflection<br>3. 能识别 Agent 失控风险，设计“最大步数熔断”与“高危动作人类确认（Human-in-the-loop）”边界 | 设计完整的 **《Agent 状态机工程蓝图》**，明确定义每个 Tool 的输入/输出结构、RAG 切片数据源、**多路径自我反思回路**及**安全熔断机制** |

## 二、核心教学隐喻（非纯 Coding 解释法）

### 1. 隐喻 A：浸泡在玻璃缸里的天才大脑（基础 LLM）
- **生活类比**：纯大语言模型就像科幻片里的**“缸中之脑”**——它博览群书、满腹经纶，却被封在一只不透风、没有网络也没接手脚的玻璃缸里。
  - 你问它：“我妈冰箱里还剩几个鸡蛋？今天北京下不下雨？”——它不知道，如果不加限制，它甚至会为了迎合你而靠概率编一个数字（幻觉）！
  - 你让它：“帮我给班主任发一封请假邮件。”——它只能帮你**写好草稿文字**，却没有手按“发送键”。

### 2. 隐喻 B：穿戴钢铁侠战甲（AI Agent 智能体）
为了把“缸中之脑”放出来真正干活，工程师为它装上了四件外骨骼战甲：
1. **感知雷达（Perception）**：能看图、听语音、读传感器、抓取实时网页的“眼睛和耳朵”。
2. **随身魔法图书馆（Memory / RAG）**：不用把全校校历、爷爷的病历硬塞进脑子，而是背着一个可随时翻查的私有活页夹（长期记忆 + 外挂知识库）。
3. **万能机械臂腰带（Tools / Function Calling）**：装上计算器、地图导航、日历写入、天气 API、Python 沙箱等“手脚”。大脑只要喊出标准化指令，机械臂就去真实世界按按钮！
4. **贾维斯战术头盔（ReAct 规划与反思循环）**：最牛的不是手脚，而是头盔里的循环系统——**先拆解任务（Thought）→ 伸出机械臂操作（Action）→ 低头看结果成没成（Observation）→ 发现闭馆/报错了？立刻骂自己一句“走错了”，换条方案重试（Reflection）！** 直到达成最终目标才脱下战甲交付结果。

### 3. 隐喻与真实原理映射及纠偏表

| 隐喻要素 | 对应 AI 真实原理 | 课堂必须戳破的常见误区 |
| :--- | :--- | :--- |
| 玻璃缸大脑（LLM） | 无状态的单轮/多轮文本预测推理模型（Stateless Inference） | ❌ 误区：“大模型记住了我上次告诉它的所有事，只是藏在脑子里” → ✅ 纠偏：模型每次推理都是健忘的金鱼，所谓的“记住”全靠外部系统把历史记录作为上下文重新塞给它 |
| 魔法活页图书馆 | RAG（Retrieval-Augmented Generation，检索增强生成）与向量记忆库 | ❌ 误区：“让 AI 学我的笔记，就得重新花几百万训练它” → ✅ 纠偏：不用重训大脑！先把笔记切成碎片放进向量星空，用时按距离捞出最相关的几页临时递给它看即可 |
| 机械臂工具腰带 | Tool Use / Function Calling / MCP 协议调用外部接口 | ❌ 误区：“AI 自己偷偷学会了操作鼠标点击网页” → ✅ 纠偏：其实是大脑输出了一段**约定好的格式口令**（如 JSON 指令），由外面的代码跑腿执行后再把结果喂回大脑 |
| 战术头盔反复复盘 | ReAct Loop（推理-行动-观察循环）与 Self-Reflection | ❌ 纠偏：Agent 不是一步到位，而是**“边干边看边改”的试错循环**；若缺乏人类设定的“最大循环次数”和“权限锁”，它可能会卡在死循环或删光文件 |

## 五、课堂互动沙盒实验引导步骤

> **对应演示工具**：**Demo 2（课件 3：Agent 时间轴动画）**

1. **Step 1：关闭所有外挂（裸奔对照组）**
   - 在课件 3 控制面板中，将 `Perception`、`RAG`、`Tools` 全部设为 `OFF`。
   - 发起预设任务：`查今天学校所在城市的空气质量，结合我上次体检报告，决定今天适合跑 800 米吗？`
   - **观察结果**：输出日志显示大模型直接无中生有编造“今日晴朗、上次体检良好”，感受“缸中之脑一本正经胡扯”的危险性。
2. **Step 2：逐一合体并单步追踪时间轴**
   - 依次点亮 `Tools（实时天气接口）` 与 `RAG（私有体检档案）`，点击 `单步运行（Step）`。
   - 观察光球每一次从 `Thought` 发出 JSON 工具调用、拿到 `Observation` 真实数据后再拼出严谨结论的全过程。
3. **Step 3：注入故障测试自我纠错（Chaos Testing）**
   - 打开面板右上角的 **“混沌故障开关”**（勾选 `天气 API 超时` 或 `目标场馆闭馆`）。
   - 对比勾选 `开启 Reflection 反思` vs `关闭反思` 的两条时间轴分支：验证没有反思回路的 Agent 会直接卡死或放弃，而具备反思回路的 Agent 能够调用备选搜索引擎或降级询问人类。
4. **教师控场与救场预案**：
   - *若学生将所有功能都叫“一个工具”，分不清 RAG 和 Tools*：用一句话区分——“**RAG 是只读不改的翻书查找（查过去积累的私有资料）；Tools 是动手干活与连接实时世界（算数学、查实时股价、发消息、写数据库）。**”

## 六、PBL 实战任务卡与 Prompt 脚手架

### 📋 任务卡：打造校园/家庭“战甲级”Agent 蓝图
- **任务情景**：观察自己一天中最琐碎、最容易遗忘或需要跨好几个软件来回倒腾的痛点（例如：**“社团活动雨天紧急改期通知官” / “外婆慢性病吃药防混淆语音管家” / “错题本拍照自动归类并出变式题教练”**）。
- **硬性架构指标**：
  1. 明确标出至少 **3 个 Tools（外部工具机械臂）**；
  2. 明确标出 **1 个私有 RAG 记忆库**（里面存什么不能公开的独家资料？）；
  3. 画出完整的 **ReAct 自我纠错回路**（如果第 2 个工具报错/查无此数据，怎么办？）；
  4. 划定 **1 条人类刹车红线**（哪一步绝不允许 AI 自己擅自按确认，必须弹窗请人点头？）。
- **交付物**：《Agent 战甲工程蓝图》（含流程图 + 工具清单 + 故障熔断表）。

### 🧩 结构化 Prompt 脚手架（学生蓝图设计 & 红队测试专用）

# 第 4 课（元学习篇·72小时领域破壁）：《干掉四年大学专业：如何用 AI 在 72 小时内吃透一个陌生硬核领域？》

## 二、核心教学隐喻（非纯 Coding 解释法）

### 1. 隐喻：空降未知大陆的“全息作战沙盘”
- **传统学法（徒步爬山模式）**：你想进入一个陌生领域（比如“合成生物学”或“太空垃圾清理”）。传统大学路径是从山脚的《基础导论》第 1 页背到《专业高阶》第 800 页。很多人背了两年概念名词，却连“这座山顶今天到底在打什么仗、哪里有宝藏”都没看见就已经耗尽兴趣。
- **AI 时代元学习（全息空降沙盘模式）**：现在你是手握全息沙盘的战地总指挥！不要按页数顺序学，而是派 AI 当侦察机，分 **四波特种侦察** 瞬间吹散迷雾：
  1. **第 1 波 · 核弹级粉碎（第一性原理 First Principles）**：不管这个领域吹得多玄乎，它永远违背不了的 3 条最底层物理/经济/生物铁律是什么？（比如太空垃圾清理逃不开“牛顿动量守恒”和“每公斤发射成本”）
  2. **第 2 波 · 翻译外星暗号（黑话降维词典）**：学术界和行业总喜欢造吓人的黑话来筑起高墙（如 `CRISPR-Cas9`、`凯斯勒综合征`）。把它们通通丢进翻译机，剥掉拉丁字母壳，露出“剪刀、胶水、连锁追尾车祸”的本质！
  3. **第 3 波 · 咬合因果齿轮网（Causal Gear Graph）**：行业不是一盘散沙，而是一组咬合的机械齿轮——哪颗齿轮转慢了（成本太高/精度不够/寿命太短），后面十颗齿轮全都卡死？
  4. **第 4 波 · 标红“大师也投降的雷区”（Open Problems）**：教科书里写满的都是“已经解决的过去”，而真正值得你投入青春和创造力的，是地图边缘闪烁红光的**“人类至今没搞定、甚至互相矛盾的未解之谜”**！

### 2. 隐喻与真实学习原理映射及纠偏表

| 隐喻要素 | 对应元学习与科研策略 | 课堂必须戳破的常见误区 |
| :--- | :--- | :--- |
| 第一性原理粉碎机 | 物理/经济学底层约束建模（First-Principles Thinking） | ❌ 误区：“先学好所有前置基础课才配看前沿难题” → ✅ 纠偏：**以终为始的“拉网式学习”**——先盯住底层物理约束和前沿真问题，反过来决定自己只需补哪几块核心基础拼图 |
| 黑话降维翻译机 | 费曼学习法（Feynman Technique）+ 领域本体映射 | ❌ 误区：“如果翻译成了大白话，是不是就不专业了？” → ✅ 纠偏：真正的科学家能用 12 岁孩子听懂的话讲清最深奥的原理；靠堆砌黑话唬人的往往自己也没想透 |
| 因果齿轮与创新反应炉 | 产业链/技术栈系统瓶颈分析（Bottleneck / TOC 约束理论）与跨界组合创新 | ❌ 误区：“只要让 AI 给我总结一份 5000 字《XX领域综述》就算吃透了” → ✅ 纠偏：被动看线性长文几乎没有留存率！必须亲手把线性文本拆解成**有因果箭头的齿轮网**，并尝试拔掉一颗齿轮看哪里会崩溃 |

## 五、课堂互动沙盒实验引导步骤

> **对应演示工具**：**Demo 3（模式 B：72小时领域破壁与创新反应炉沙盘）**

1. **Step 1：启动“黑话降维器”**
   - 在 Demo 3 模式 B 顶部选择示例硬核领域（如 `太空碎片清理` 或 `垂直农业`）。
   - 关闭“大白话模式”先看满屏学术名词，感受压力；随后一键打开 `降维翻译`，逐个点击黑话节点对比真实本质。
2. **Step 2：因果齿轮“拔钉子”测试（寻找真瓶颈）**
   - 试着点击沙盘里的不同齿轮，将其中一颗切换为 `瓶颈卡死状态` 或点击 `优化突破 10 倍`：
   - **对比观察**：优化“种植架外观美观度”齿轮，下游成本齿轮纹丝不动；而将“LED 光合效率/自动化采摘成本”齿轮突破 10 倍，观察整张沙盘超过 60% 的齿轮瞬间亮起绿色加速！借此领悟什么是**关键卡点（Leveraging Point）**。
3. **Step 3：点亮“创新反应炉”**
   - 从沙盘边缘选定 1 个闪烁红光的 `Open Problem` 拖入底部的“创新反应炉”，再从右侧跨界元素库中拖入 1 个完全不相干的技术或生活机制（例如：`抓娃娃机力学` / `蚂蚁信息素算法` / `奶茶封口膜`），点击 `激发碰撞`，查看系统推演出的跨界破局灵感与反驳风险。
4. **教师控场与救场预案**：
   - *若学生觉得“AI 给的 Open Problems 太大太虚（如‘提高电池能量密度’）”*：教学生立刻下达**“显微镜下切一刀”指令**——“不要停在宏观大词上，追问 AI：‘要把这个大难题拆解成具体到某一个场景、某一种材料的 3 个具体物理矛盾，是哪 3 个？’”

### 📋 任务卡：72 小时硬核领域破壁作战书

  1. 🧬 **合成生物学（Synthetic Biology）** —— 把细胞当成可编程的微型工厂
  2. 🧠 **脑机接口（Brain-Computer Interface, BCI）** —— 在碳基神经元与硅基芯片间搭桥
  3. 🛰️ **太空碎片清理（Space Debris Removal）** —— 给拥挤在近地轨道的“太空高速子弹”做大扫除
  4. 🌱 **垂直农业（Vertical Farming）** —— 在摩天大楼里不靠泥土和太阳种粮食
- **72 小时节奏分配**：
  - **课堂前 2h（闪电侦察）**：完成《领域沙盘初稿》（3 条第一性原理 + 5 个神级黑话比喻 + 1 张因果瓶颈树）；

### 🧩 结构化 Prompt 脚手架（四波特种侦察流水线）

```markdown
【侦察总令】
我将用 72 小时攻克一个我完全陌生的硬核领域：【填入抽签领域，如：太空碎片清理】。
请严禁给我输出长篇大论的百科综述！现在我们按“四波侦察协议”逐波推进，每一步只执行当前指令，等我确认后再进下一步。

=== 第一波：第一性原理粉碎 ===
请剥掉所有工程细节和公司宣传，告诉我这个领域绝对无法违背的 **3 条最底层物理/化学/经济学铁律**（例如能量、动量、热力学或单位成本铁律），并用一句话解释违背它的后果。

=== 第二波：外星黑话降维器 ===
请列出新手进入这个领域最容易被吓唬住的 **6 个核心硬核术语**。
格式要求：`术语名称` → `一句话大白话（必须用初中生日常物品做比喻，如快递站、拉链、高速公路堵车）` → `为什么行业离不开它`。

=== 第三波：因果齿轮与瓶颈定位 ===
如果我要把这个领域里的某项核心技术成本降到现在的 1/10，请画出一条 5 步因果链，并指出**哪一颗齿轮卡得最死**（是材料寿命、能量转换、法规审批还是物理精度）？

=== 第四波：寻找 Open Problems 与交叉验证 ===
请列出该领域目前全人类科学家和工程师**至今没解决、且存在激烈路线争论的 3 个具体未解之谜（Open Problems）**。
【防幻觉追问】：请给出我可以直接去权威学术网站或科普媒体检索验证的 **中英文精确关键词组合**，不要自己编造论文标题。
```

# 第 5 课（立足点篇·品味与问题定义）：《当答案变得一文不值，好问题值一亿美金：寻找你的生态位》

## 一、课程定位与年级适配

- **课程定位**：全课程的“灵魂转折课”。在前 4 课看清 AI 的原理、战甲与学习威力后，学生极易陷入“既然 AI 啥都会、算得比我快一万倍，那人类青少年还学什么、干什么？”的深层焦虑。本课正面确立**人类在 AI 时代的不可替代生态位**。
- **核心突破点**：从“追逐标准答案的做题家”觉醒为“拥有生命痛感、审美直觉（Taste）与问题定义权（Problem Framing）的指挥家”。明白**数据中心里的 AI 没有身体、没有青春、没有叹息——它感知不到人类生活中最真实的隐性需求**。

| 适配学段 | 认知起点与难点 | 分层教学目标 | PBL 产出复杂度要求 |
| :--- | :--- | :--- | :--- |
| **初中组（7–9 年级）** | 习惯在考试里等待老师出好题，自己只要答对就能得高分；把“用户需求”想象成“AI 能帮我写作业” | 1. 能区分“平庸而正确的 AI 答案”与“有温度、有洞察的真问题”<br>2. 学会用“田野观察耳目”代替“坐在教室里空想需求”<br>3. 掌握“把大问题改写成小而精准的好问题”的 **Problem Reframing（重框术）** | 课后真实访谈 **1 位非技术身边人**（保安/阿姨/长辈/手艺人），填写 **《10 分钟痛点观察日记》** 与 **1 张重框后的《好问题提案卡》** |
| **高中组（10–12 年级）** | 具备较强的社会观察敏锐度与审美判断潜力，但做项目时常陷入“为了炫技而硬套 AI 功能”的伪需求陷阱 | 1. 理解 **Taste（审美品味）** 的本质不是“好不好看”，而是“在 100 个 AI 庸常方案中敢于否决 99 个的判断基准”<br>2. 熟练运用 **“表层抱怨 → 隐性行为摩擦 → 问题重框（Reframing）”** 三级跳法<br>3. 能清晰界定哪些问题该由 AI 计算处理，哪些温度必须留给人类连接 | 开展深度 **田野访谈（≥2 人，带录音/现场行为观察笔记）**，完成 **《田野盲区诊断书》**，对比 AI 机房闭门造车方案与田野重构方案的本质差异，锁定 **第 6 课原型开发选题** |

## 二、核心教学隐喻（非纯 Coding 解释法）

### 1. 隐喻：永动机交响乐团 vs 站在指挥台上的少年
- **过去的焦虑**：从前你想演奏一部交响曲，得自己苦练 10 年小提琴、再花 10 年背总谱、招 80 个乐手。谁背得熟、拉得准，谁就是赢家。
- **今天的真相**：AI 是一支**拥有十万名顶级乐手、永不疲倦、一秒就能按曲谱完美吹拉弹唱的“永动机交响乐团”**。正因为演奏技巧（给出标准答案）已经免费且过剩，所以**“答对题”正在变得一文不值**。
- **指挥家的三重不可替代天赋**：
  1. **生命体验与同理心（Empathy）**：乐团里的机器人手再稳，也从来没有在凌晨五点帮摆摊的外婆推过三轮车，没体验过考试失利后走过夜路的微风。**只有活生生的人，才知道哪里真疼、哪里值得守护。**
  2. **审美直觉与品味（Taste）**：乐团一口气给你吐出 100 段旋律，99 段都很工整但毫无灵魂。**指挥棒敲响哪一段、克制地删掉哪十个多余音符**，这就是你的品味。
  3. **问题定义权（Problem Framing）**：同样面临“老人记不住吃药”，平庸提问是 *“做一个带 10 个闹铃的吃药提醒 App”*（老人根本嫌吵嫌字小直接卸载）；好问题是 *“如何让不爱看手机的爷爷，在每天习惯拧开保温杯喝第一口温水时，顺便听见孙女温柔报出一句吃药提示？”* **换一个问题框，答案的价值瞬间相差一亿倍！**

### 2. 隐喻与真实创新方法论映射及纠偏表

| 隐喻要素 | 对应真实创新能力 | 课堂必须戳破的常见误区 |
| :--- | :--- | :--- |
| 十万乐手交响乐团 | 规模化、低边际成本的生成式 AI 算力与知识供给 | ❌ 误区：“既然 AI 这么厉害，人类只要负责躺在旁边点鼠标就行了” → ✅ 纠偏：**没有灵魂指挥家的交响乐团，只会用一万倍的速度制造平庸噪音（AI Slop）** |
| 指挥家的品味（Taste） | 高标准信息筛选力、人性洞察与产品克制感（Curation & Judgment） | ❌ 误区：“品味就是个人喜欢什么颜色或字体的主观玄学” → ✅ 纠偏：真正的 Taste 是**“见过足够多顶级好东西之后，对平庸、繁琐和虚假的本能生理性排斥”** |
| 重新定义问题（Problem Framing） | 设计思维（Design Thinking）中的真实痛点重框与场景切入 | ❌ 误区：“向 AI 提问越长越好，直接问‘给我 10 个创业好点子’就行” → ✅ 纠偏：**机房里的 AI 只知道全网重复了十万次的二手陈词滥调**；一线田野里观察到的一个小动作，才是一亿美金问题的源头 |

## 五、课堂互动沙盒实验引导步骤

> **对应演示工具**：**Demo 2（互动讲义对比演示）**

1. **Step 1：拉动对比卷帘，诊断“AI 味儿”病因**
   - 在 Demo 2 对比演示页面，切换 3 个预设生活议题（`独居老人工具` / `初中生错题本` / `老街手艺人卖货`）。
   - 将中间对比手柄先全部拖向右侧（只展示左侧 AI 机房自动生成版），请学生用红笔圈出 3 个让人不想用的原因（通常是：**步骤太多、忽视物理限制、缺乏情感信任、术语傲慢**）。
2. **Step 2：体验“问题重框手术（Reframing）”**
   - 慢慢把分隔卷帘拖回左侧，揭晓右侧“经过人类田野观察重构后”的方案；
   - 点击对比面板中的 **`查看田野隐藏线索`** 按钮，查看改变整个方案的仅仅是一句极其微小的观察细节（例如：“手艺人手指沾满泥巴和颜料，**根本没法腾出手在手机屏幕上打字！**”）。
3. **Step 3：即时反刍测试**
   - 在互动讲义底部的“问题重框练习框”输入一个你刚才随便想出的平庸需求，点击 **`AI 盲区体检`**，系统会故意以“真实用户吐槽”的口吻反驳你 3 句话，强迫你修改出更贴地气的问题描述。
4. **教师控场与救场预案**：
   - *若学生觉得“去外面问真实陌生人太社恐、不敢开口怎么办？”*：允许先从最亲近但**“日常角色完全不同”**的人开始（如爷爷奶奶、每天在学校门口见面的宿管阿姨/门卫叔叔、家里常去的那家早餐店老板），并教学生一句破冰万能开场白：“**叔叔/奶奶，我学校科技课在做个小观察作业，想听听您平时干活最烦哪件小事，不用客气，随便吐槽就行！**”

## 六、PBL 实战任务卡与 Prompt 脚手架

### 📋 任务卡：走出教室的田野调查——寻找“一亿美金好问题”
- **行动铁律（硬性门槛）**：**禁止在宿舍/书房闭门拍脑袋！** 必须真实观察并访谈至少 **1 位与你生活圈完全不同的人**（手艺人、高龄长辈、外卖骑手、食堂工作人员、社区医生、菜市场摊主或老师）。
- **访谈 3 不准**：不推销你的 AI 创意；不问“你觉得要是有个 AI 机器人好不好”；不替对方下结论。
- **采集物（Field Evidence）**：带回 **1 个具体发生过的麻烦瞬间**（几分几秒、在哪里、因为什么物理或心理障碍卡住了）+ **1 句受访者的原话金句**。
- **交付物**：《一亿美金好问题提案卡》（包含：受访者画像与真实故事 → 原始平庸问题 vs 重框后的好问题 → 准备在第 6 课用什么极简原型帮到 TA）。

### 🧩 结构化 Prompt 脚手架（田野洞察分析师 & 问题重框器）

```markdown
【角色与禁止事项】
你现在是一位敏锐的人类学家与“问题重框教练”。
警告：严禁一上来就给我生成“App 功能清单”或“高大上商业模式”！你必须帮我盯住真实人类的血肉细节。

=== 阶段一：出征前生成“不带偏见的访谈提纲” ===
我想去访谈的对象是：【例如：社区门口摆摊修鞋补衣服 20 年的阿姨】。
请帮我设计 5 个**不提“AI、软件、自动化”任何技术词汇**的聊天问题，帮我挖掘出她每天手头工作中最重复、最费眼神、或者最容易和顾客产生沟通误会的 10 分钟。

=== 阶段二：带回田野故事后，执行“问题重框手术” ===
【我访谈到的真实观察与原话】：[学生填入真实的观察细节，例如：阿姨其实记性很好，但经常忙起来忘了哪位客人叮嘱过“这双鞋鞋底不能用强力胶会开裂”，她眼睛花，不想在手机里打字记录，习惯在鞋面上夹一张手写小纸条，经常掉……]

请你帮我对比分析：
1. 如果一个没去过鞋摊的程序员用 AI 瞎猜，他会做出什么“自以为是但阿姨绝对不用的蠢产品”？
2. 基于“双手沾着胶水不能打字 + 眼睛老花 + 喜欢物理夹纸条”这些约束，帮我把痛点**重新定义（Reframe）**成 3 个极其巧妙、反直觉的好问题切入点！
```

# 第 6 课（创造篇·一人独角兽路演）：《Vibe Prototyping：把你的创新 Idea 变成可交互现实》

## 一、课程定位与年级适配

- **课程定位**：整套 6 节标杆示范课的“终极收获节”与 **Demo Day 实战舞台**。将前 5 课的全部积淀——**语义空间直觉（L1）+ 控温防幻觉机制（L2）+ Agent 工具闭环（L3）+ 72h 领域破壁图谱（L4）+ 田野一亿美金好问题（L5）**——全部锻造为一个**摸得着、点得动、能现场交互的最小可行性魔法（MVM, Minimum Viable Magic）**！
- **核心突破点**：打破“我不会写后端、不会搭服务器、不会前端框架，所以我的创意只能停留在 PPT 上”的自我设限，掌握 **Vibe Prototyping（直觉与氛围驱动的极速原型法）**——用自然语言描述与结构化迭代，像导演一样把脑中的魔法在几十分钟内炼成可运行的数字现实。

| 适配学段 | 认知起点与难点 | 分层教学目标 | PBL 产出复杂度要求 |
| :--- | :--- | :--- | :--- |
| **初中组（7–9 年级）** | 几乎没有独立前端/代码开发经验；容易把“原型”理解成画几张静态 PPT 假按钮，或者一口气向 AI 要“完整抖音/微信”导致代码彻底跑不起来 | 1. 掌握 **MVM（最小可行性魔法）** 原则：砍掉登录注册与复杂后台，只做最亮眼的 1 个核心交互<br>2. 学会用“3 轮三明治对话法”指挥 AI 生成一个单文件 HTML 可点击交互网页/互动故事卡<br>3. 能在 5 分钟路演里讲清“问题故事 + 现场点动演示” | 独立或小组炼出 **1 个单页可点动交互原型（HTML/互动分镜）**，完成包含“田野痛点+核心交互演示”的 **5 分钟 Demo Day 路演** |
| **高中组（10–12 年级）** | 多数具备一定编程或网页基础，但极易陷入“技术细节沉迷”（花 80% 时间调数据库/写注册页，却没展示出真正的 AI 创新力） | 1. 精通 **Vibe Debugging（直觉排错与局部迭代）**：精准描述期望现象与报错上下文，不盲目整段重生成<br>2. 学会把课程三大工程范式（**故事引子 + 原理流向图 + 可交互沙盒控件**）整合进路演结构<br>3. 能清楚论证自己原型的 **Agent 工具边界、Temperature 选择与幻觉防线** | 炼出 **高度完成度的可交互 Web 原型/模拟 Agent 沙盒**（带真实模拟数据流与边界异常演练），在 5 分钟内完成 **“72h 领域图谱 + 田野洞察 + MVM 现场 Demo + 2 分钟犀利答辩”** |

## 二、核心教学隐喻（非纯 Coding 解释法）

### 1. 隐喻：炼金术士的创客工坊与“最小可行性魔法（MVM）”
- **传统作坊的叹息（MVP 之前的漫长黑夜）**：以前做一个产品原型（Minimum Viable Product），就像盖一栋十层大楼：哪怕你只想验证“屋顶花园能不能让人开心”，你也被迫先挖三个月地基（配环境）、砌承重墙（写登录注册）、铺水管（建数据库）——等终于把门装上，你的创意激情早就冷掉了。
- **Vibe Prototyping 炼金工坊（MVM）**：今天的 AI 时代，你是站在魔法坩埚旁的炼金术士，手握两样神器：**“分镜剧本（清晰的场景与交互逻辑）” + “自然语言咒语（Prompt）”**。
  - **什么叫 MVM（Minimum Viable Magic，最小可行性魔法）？** 不需要造整栋大厦！你只需要炼出**“让人在 10 秒钟内‘哇塞’一声的那个核心魔法瞬间”**。比如：如果你做的是“菜市场老奶奶音声记账伴侣”，你的 MVM 根本不需要什么“微信扫码登录、修改头像、VIP 充值页面”——只需要打开网页后，点一下硕大的绿色麦克风按钮、输入一句带口音的方言菜名，大屏瞬间吐出大号手写体账单和温柔的确认回声，Magic 就发生了！

## 五、课堂互动沙盒实验引导步骤

> **对应教学工具**：**“15 分钟极速炼金沙盒”（教师示范 + 学生单文件 HTML/JS 原型调优环境）**

1. **Step 1：做减法——填写《MVM 需求三明治卡片》**
   - 严禁直接打开 AI 对话框写“帮我做个 XXX 网站”。学生必须在草稿纸上先填满三层三明治：
     - **面包顶层（Vibe 视觉气质）**：要像手绘笔记本、复古木头收音机，还是深蓝科学沙盒？主色调不超过 2 个。
     - **核心肉馅（唯一魔法交互）**：用户点哪 1 个按钮 / 输哪 1 句话 / 拖哪 1 个滑块，屏幕发生什么立竿见影的变化？
     - **面包底层（防翻车模拟数据）**：由于 30 分钟不接真实付费大模型接口，提前内置 3 组逼真好玩的预设测试样例（含 1 个故意出错触发 Agent 反思的样例）！
2. **Step 2：第 1 轮出骨架（拿到能跑的界面）**
   - 复制下方《Vibe Prototyping 脚手架》，要求 AI 输出**“单个完整 HTML 文件（包含内嵌 CSS 与 JS，无需安装任何依赖，双击浏览器就能打开）”**。
   - 保存为 `demo.html` 并在浏览器打开，确认核心按钮能点动。
3. **Step 3：第 2–3 轮 Vibe Debugging（当好导演，不当敲代码机器）**
   - 如果页面太丑或某个点击没反应，**禁止说“重做一份”**！使用“导演式精准微调句式”：
     - *界面审美微调*：“功能全对，但现在太像程序员写的灰色表格了！请把按钮放大一倍，配色改成暖米纸张底色配墨绿色（像给长辈用的温和卡片），把多余的统计数字全部删掉。”
     - *交互报错排错*：“我点击【开始检测】按钮后没有任何反应，按 F12 控制台显示这行红字：`[粘贴报错文本]`，请只修改相关点击逻辑并告诉我你修了哪一处。”
4. **教师控场与救场预案**：
   - *若遇到个别小组距离路演只剩 5 分钟代码彻底改崩、页面白屏*：立即启动**“30 秒保底降落伞方案”**——保留一页简洁大字故事卡，把原型的“理想交互状态 1 / 状态 2 / 反思报错状态 3”用极简 HTML 切换按钮（点击换卡片）串起来，“先把魔法的剧本演给观众看，绝不空手下台！”

## 六、PBL 实战任务卡与 Prompt 脚手架

### 📋 任务卡：后大学时代青年创新 Demo Day（5 分钟一人独角兽路演）
- **路演时间分配（总计 5:00，超时即响铃）**：
  - `0:00 – 0:45`：**我是如何吃透陌生领域的**（展示第 4 课《72h 破壁图谱》中最精华的 1 个因果瓶颈或 Open Problem）；
  - `0:45 – 1:30`：**我遇到了谁，发现了什么一亿美金痛点**（展示第 5 课田野调查真人照片/故事金句与重框后的好问题）；
  - `1:30 – 3:00`：**现场可交互魔法演示（MVM Demo）**（现场操作运行网页原型或互动沙盒，演示正常流 + 1 次抗幻觉/自我纠错流）；
  - `3:00 – 5:00`：**硬核答辩环节**（接受同学与导师关于“是不是伪需求 / AI 幻觉怎么防 / 凭啥非得用 AI”的 2 分钟拷问）。

### 🧩 结构化 Prompt 脚手架（Vibe Prototyping 炼金三轮咒语）

#### 第 1 轮：生成单个可零配置运行的 MVM 原型
```markdown
【角色定位】
你是一位极具审美品味的“全栈创意原型设计师”。请帮我把一个温暖、精准的创意，在 1 分钟内变成一个**单个独立的 HTML 文件**（内部自带样式与交互 JS，不依赖外部构建工具，用户双击就能直接在浏览器里交互演示）。

【我的 MVM 核心需求三明治】
1. **解决谁的什么痛点（来自真实田野观察）**：[填入第 5 课重框后的痛点，例如：手上有胶水的修鞋阿姨不方便打字记账，且容易忘记顾客“不能用强力胶”的特殊叮嘱]
2. **视觉气质（Vibe）**：[例如：温暖手账牛皮纸质感、大字号高对比度、极简克制，屏幕最多同时出现 3 个核心视觉区]
3. **唯一核心魔法交互（Core Magic）**：
   - 当用户点击【按住模拟说话】并选择下面 3 个真实测试案例之一时：[案例 A 正常订单；案例 B 含糊口音触发反思；案例 C 发现“鞋材与强力胶冲突”触发红色安全警报]；
   - 页面右侧同步展开一个微小的“AI 思考透明窗”，像《Agent 时间轴》一样逐条高亮显示：`1. 感知语音 → 2. 查询记忆库(RAG)发现材质禁忌 → 3. 弹出大字语音确认卡`。

【硬性要求】
- 禁止生成“用户登录/注册/设置/广告弹窗”等一切无关废页！
- 直接输出完整可运行的单文件 HTML 代码。
```

#### 第 2 轮：审美手术与人文细节打磨（运行首版后使用）
```markdown
刚才那版能跑通了，但作为挑剔的“指挥家”，我觉得还不够打动人。请你做以下 3 处精准修改（不要改动已经跑通的底层切换逻辑）：
1. 【减法与克制】：请删掉页面底部的“使用统计报表”和多余的小图标，把主操作按钮做得像真实物理按键一样有按压反馈。
2. 【防幻觉边界可视化】：在案例 C 触发“材质冲突警报”时，请增加一个必须由人点击的【我已知晓并确认更改方案】刹车按钮，体现 Human-in-the-loop。
3. 【质感升级】：请加上流畅的 CSS 动画过渡，让文字卡片弹出时不要生硬闪现，而是像抽出一张牛皮纸工单一样顺滑。
```

## 七、创新能力评估 Rubric（无标准答案评分表）

> **路演评审核心原则**：不看谁调的网页特效最花哨、不看谁用的大模型词汇最高深；重点考察**“真领域洞察 + 真人间痛点 + 巧技术边界 + 好审美品味”**的完整闭环。

| 评估维度 | 1 分：萌芽探索 | 2 分：合格实践 | 3 分：优秀跃迁 | 4 分：标杆突破 |
| :--- | :--- | :--- | :--- | :--- |
| **端到端闭环完整性** | 路演各环节割裂：前面讲的领域和中间田野、后面原型毫无关系 | 勉强串联了痛点和演示，但领域破壁逻辑较为单薄 | 72h 领域卡点 → 田野真痛点 → MVM 原型交互三环紧密咬合，因果连贯 | 闭环自洽且充满宿命感与惊喜感，让人瞬间明白“为什么必须由这个洞察长出这个原型” |
| **MVM 克制力与交互魔力** | 只展示了几张静态画板，或生成了一个点不开、满屏报错的半成品 | 跑通了简单点击界面，但掺杂了大量假登录页与无用按钮 | 界面极简克制，10 秒内即展现出核心魔法瞬间，并能现场应对 1 个异常演示 | 交互细节极具“Vibe 灵魂与温度”，观众甚至当场产生“明天就想拿去给受访者试一试”的冲动 |
| **AI 机制把控与边界清醒度** | 把 AI 当成无所不能的许愿神灯，被问到“幻觉或断网怎么办”时哑口无言 | 口头补充了“我们会提醒用户注意核实信息” | 在原型和答辩中明确标出了 RAG 数据源、参数控温策略及不可逆动作的人类刹车点 | 对“哪里该用极简传统规则代码、哪里才值得放手让 Agent 推理”有着远超年龄的工程清醒 |
| **路演叙事与指挥家气场** | 全程低头念文字稿，像在做软件说明书汇报 | 声音清晰，按顺序介绍完了各个模块 | 完美运用“故事先导 + 对比拆解 + 现场把玩”节奏，有眼神交流与感染力 | 面对导师犀利追问不慌不忙，坦然承认原型局限同时自信捍卫核心问题定义权，尽显创造者格局 |
